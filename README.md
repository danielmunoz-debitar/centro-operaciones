# DEBITAR Centro de Operaciones v0.6

Versión local/offline-first. Cambios principales: tema claro, navegación lateral doble en escritorio, navegación móvil enfocada en Ingresos/Gastos/Uber/Respaldo, gastos categorizados por categoría/naturaleza/tipo, deudas con cuotas vinculadas a gastos y proyección, Uber con km fuera de app y creación automática del ingreso neto al cerrar jornada, y estructura inicial de Proyectos.

## Instalación GitHub Pages
Reemplazar los archivos del repositorio por estos archivos y publicar desde la rama configurada en GitHub Pages. Si el navegador conserva una versión anterior, recargar sin caché o cerrar/reabrir la PWA.

## Datos
La v0.6 usa la clave local `debitar_ops_v06`. Para recuperar datos anteriores, use Configuración > Importar JSON con el respaldo exportado. Antes de importar en otro dispositivo, exporte el respaldo de ese dispositivo.
